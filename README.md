# Course-Sim

Interactive educational simulations for learning **AI Foundation concepts** in a visual and practical way.

From understanding **Data** to experiencing **Machine Learning**, this project transforms theoretical concepts into interactive simulations.

## Live Learning Path

Data
↓
Programming
↓
Algorithms
↓
Machine Learning
↓
Artificial Intelligence

---

## About

Course-Sim is an educational project designed to teach students AI concepts using interactive simulations instead of traditional slides.

Students learn by:

* Dragging
* Sorting
* Building
* Simulating
* Observing outcomes

All lessons are designed to be beginner friendly.

Language Support:

* English
* Nepali Romanized

## Installation

Clone repository

```bash
git clone https://github.com/YOUR_USERNAME/Course-Sim.git
```

Open project

```bash
cd Course-Sim
```

Install

```bash
npm install
```

Run

```bash
npm run dev
```

Build

```bash
npm run build
```
